## 03 / 开始使用

将 [AI 读取入口](https://github.com/zhx056138-dotcom/hengxuan/blob/main/START-HERE.md) 发给支持访问 GitHub 的 AI。

无法访问链接时，复制入口和相关文档正文，或下载仓库文件上传给 AI。只有具备仓库写入权限的工具才能直接保存修改；普通聊天不会自动同步。

换电脑后，可以登录 GitHub 查看，或克隆仓库。已有本地副本时，开始工作前拉取最新版本；完成修改后提交并推送。
